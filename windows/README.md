# 傻瓜版：单个 exe，零依赖

**给不想装 Python 的人用。** 双击 `鑫洋V8电梯卡工具.exe` 就能跑 —— 不装 Python、不装运行库、
不需要联网（用的是 Windows 自带的 .NET Framework 4.x，Win10/Win11 都有）。

- 体积：**约 43 KB**
- 三个页签：**① 懒人改卡**（打开 dump → 自动检测 → 延时 + 改楼层 + 可选清滚动码 → 存新 dump）
  / **② 算卡密码**（由 UID 直接算扇区密钥）/ **③ 手动计算**（只算日期、只算楼层、只算某个字段）
- 算法与 Python 版**完全一致**，自检 **10/10**（`--selftest` 会把结果写进 `自检结果_selftest.txt`）
- **深色界面**：顶部整行「使用说明」→ 左栏「检测结果」竖框 + 底部「日志」（打开卡就把 UID / 密钥核对 / 校验码 /
  日期密文 / 楼层密文 / 自动读出的日与月份候选全部写进日志）→ 右栏就是所有编辑操作
- **「年」留空不瞎填**（年份被每卡密钥流加密，读不出来），旁边红字说明要照读卡工具或物业填；
  「月」只给候选（第 4 位在高字节里），自动读出的「日」是准确的
- 楼层密文**单独一行完整显示 7 字节**（不会被截断）；右栏有 **「详细说明（原理）」按钮**，点开是一整页
  原理说明（密文怎么来的、为什么不要密码、有效期/楼层怎么算、校验码规则、什么读不出来）
- 楼层支持 **1~56 层**（位图 7 字节 = 56 位；`57` 及以上会拒绝）
- **「不改楼层／改楼层」二选一**，默认「不改楼层（卡上原样）」—— 不动楼层时那几个输入框是灰的，不用管；
  真改楼层时「现在开通」**必须照别的软件（PCR532 等）读出来的真实楼层填，不能猜**：
  差量是按这个值算的，填错 → 写进卡的楼层整个位图都错位（例：卡上真的 `2-11`，你按 `1-11` 当旧的填，
  改出来会变成 `1-11`），而且工具没法替你核对 —— 楼层在密文里读不出来
- `位0 算负一层(B1)` 只在卡上真有 B1 时才勾，看不懂就别勾（① 懒人页和 ③ 手动计算页各有各的开关，互不影响）
- `--inspect <dump>`：无界面检测（结果写 `xxx_检测.txt`）；`--open <dump>`：启动直接加载卡

## 怎么用（推荐流程）

1. 用读卡器/分析软件把卡导出一个 `.dump` 文件
2. 双击 exe →「打开卡文件(dump)…」→ 它会自动读出：
   UID、扇区密钥（并和卡里实际的密钥交叉验证）、校验码、**到期日的「日」**、月份候选、楼层字段密文
   （「日」是准确的：日期低字节的固定掩码 `D4` 实测吻合。
   月份的第 4 位在高字节里、被每卡密钥流加密，读不出来，所以只给 1~2 个候选，用「日」筛掉不存在的日期 ——
   例：读出「日=31、候选=4 或 12」→ 4月31日不存在 → 只能 12 月，工具直接预填 12）
3. 填「这张卡现在的有效期」（**年要你自己填**，月/日它会自动读出并帮你核对）
   （年份在密文里读不出来 —— 那是每卡一套的密钥流）
4. 选延时几年/几个月，或者直接指定新日期
5. 要改楼层：把「改楼层」选上 →「现在开通」填**别的软件读出来的真实楼层**→「想改成」填想要的；
   不改楼层就别动（默认就是「不改楼层（卡上原样）」，输入框是灰的）
6. 「生成新文件…」→ 得到改好的 dump，同时列出改了哪几个字节。想先弄懂原理，点右栏
   **「详细说明（原理）」** 按钮，会弹出一整页说明。

## 源码 & 自己编译

- 源码：`XyV8Tool.cs`（单文件，C# 5）
- 编译：双击 `build.bat`，或手动跑
  ```
  %WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe ^
    /out:鑫洋V8电梯卡工具.exe /r:System.Windows.Forms.dll /r:System.Drawing.dll XyV8Tool.cs
  ```
- 不需要 Visual Studio，也不需要装任何 SDK。

## 注意

- 首次运行如果被 Windows SmartScreen 拦（未签名），点「更多信息 → 仍要运行」即可。
- 只支持 **鑫洋V8** 这一族（数据在扇区1、滚动码在扇区10）；V9/V10/V11 的扇区密钥常数表不同。
- 详细原理和验证过程见仓库根目录的 `README.md`。
